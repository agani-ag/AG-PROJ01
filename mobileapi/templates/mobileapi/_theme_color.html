Include inside : {% include "mobileapi/_theme_color.html" with light="#ffffff" dark="#0f1622" %} The script puts one unscoped theme-color in front of the media-scoped pair and keeps it on whichever colour matches the current light/dark mode. The app's WebView reads only the FIRST , so without it a dark page would always get the light colour. Browsers that honour the media queries are unaffected: the unscoped tag always agrees with them. {% endcomment %}
